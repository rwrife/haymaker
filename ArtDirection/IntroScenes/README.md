# Character introduction portraits

Eight user-supplied PNG graphics are archived here as source art. Byte-for-byte copies are bundled in the app's `*-intro` image assets and shown as face close-ups in the pre-fight versus dialog. Every career bout, sparring round and rematch waits for the player to ring the bell.

All eight files are 1024 × 1536 RGBA PNGs, preserved byte-for-byte from the supplied files. Only Sylvie's filename is normalized. The portraits include a dark atmospheric glow around the figures and have varying alpha (observed range 0–254); preserve that alpha when compositing and review the result against the intended scene background. They are not cropped character cutouts or sprite sheets. No Mack intro portrait was supplied in this batch.

See [character backstories](../character-backstories.md) for character motivations, fighting identities, and sample intro dialogue. These supplied files are distinct from the earlier concept reference images in the parent directory.
